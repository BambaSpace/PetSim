# PetSim (ペットお迎えシミュレーター)

これから犬を飼いたいユーザーが、犬種ごとの特徴や「生涯にかかる概算費用」をひと目で比較・シミュレーションできる軽量アプリケーションです。
各種オプションを選ぶことで、よりリアルな飼育コストを可視化できます。

## 主な機能

*   **犬種の選択と比較**: 小型犬・中型犬・大型犬に分類された14種類の人気犬種から選択可能。犬種ごとの寿命、食費、トリミング代がプリセットされています。
*   **絞り込みと検索**: 犬種名や特徴、サイズ、「一人暮らし向け」などのタグによる素早い絞り込みが可能です。
*   **詳細な飼育オプションの設定**:
    *   ペット保険の有無
    *   トリミングの頻度
    *   おやつ・サプリメントのグレード
    *   トイレシート等消耗品のグレード
    *   ペットホテル・ドッグランの利用頻度
    *   初期のプロのしつけ教室利用
*   **生涯費用の可視化 (円グラフ表示)**: 計算された初期費用、食費・日用品、美容・お世話、医療・保険の内訳を美しい円グラフで表示します。
*   **シニア期の医療費考慮**: 犬が7歳以上（シニア期）になると、医療費や保険関連のコストが1.5倍に増加するリアルな計算ロジックを導入しています。

## 技術スタック

*   **Framework**: React (TypeScript) + Vite
*   **Styling**: Tailwind CSS (@tailwindcss/vite)
*   **Charts**: Recharts

## ローカル環境での動かし方

Node.js (v18以降を推奨) がインストールされている環境で以下の手順を実行してください。

```bash
# 1. 依存関係のインストール
npm install

# 2. 開発用サーバーの起動
npm run dev

# 3. ブラウザで http://localhost:5173 にアクセス
```

## ビルド手順

本番環境向けにビルドする場合は以下のコマンドを実行します。

```bash
npm run build
```
ビルドされたファイルは `dist` フォルダに出力されます。

## Webアプリとしての公開（ユーザーへの展開）手順

このアプリケーションはバックエンドサーバーを必要としない**完全なフロントエンド単体（SPA）**であるため、静的サイトホスティングサービスを利用することで無料で簡単に公開・運用が可能です。
本リポジトリは、**GitHub Pages** を用いてコードをプッシュするだけで自動で公開（自動デプロイ）されるように構成されています。

### 自動デプロイの仕組み (CI/CD)

1. **コードのプッシュ**:
   手元のパソコンでコードを修正し、GitHubの `main` ブランチにPushします。
2. **GitHub Actions の自動実行**:
   `.github/workflows/deploy.yml` の設定により、GitHubのサーバー上で自動的に `npm run build` が実行され、最新の `dist` フォルダが生成されます。
3. **GitHub Pages への公開**:
   ビルドされたファイルが自動的に GitHub Pages の環境にデプロイされます。特別なサーバー構築や手動アップロードは一切不要です。

### ユーザーへ展開（共有）する方法

デプロイが完了すると、以下のURLで世界中からアクセスできるようになります。
このURLをSNS（XやLINEなど）やブログで共有するだけで、ユーザーはアプリのインストール不要でシミュレーターを利用できます。

**公開URL:**
👉 `https://BambaSpace.github.io/PetSim/`

上記のURLをコピーして、ブラウザやスマートフォンのURL欄に貼り付けるだけで、誰でもすぐにアプリを利用できます！

*※ アプリ画面下部にある「X (Twitter) で結果をシェア」ボタンからも、上記URLを含んだ形でユーザー自身がシミュレーション結果を拡散できる仕組みになっています。*

### GitHub Pagesを有効にする初期設定 (初回のみ)

もし、ご自身のGitHubリポジトリで初めてこの機能を使う場合は、以下の設定を行ってください。

1. GitHubのリポジトリページを開き、**「Settings」** タブをクリックします。
2. 左サイドバーから **「Pages」** を選択します。
3. **Build and deployment** の **Source** を `Deploy from a branch` から **`GitHub Actions`** に変更します。
4. これで完了です。次回以降 `main` ブランチにPushするたびに自動で公開されます。
